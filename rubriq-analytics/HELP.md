# RubriQ Analytics — Step-by-Step Help Guide

## How to Generate a Complete Rubric Analysis

Follow these steps in order. Each step builds on the previous one.

---

## STEP 1 — Academic Setup

**Go to:** Sidebar → Academic Setup

1. Click **Add Institution** → Enter institution name, code, address, accreditation body → Save
2. Click **Add Department** → Select institution, enter department name and code → Save

---

## STEP 2 — Programs & Courses

**Go to:** Sidebar → Programs & Courses

1. Click **Add Program** → Select department, enter program name (e.g. MBA Finance), code, duration, level → Save
2. Click **Add Course** → Select program, enter course name, code, credits, semester → Save

---

## STEP 3 — Evaluation Plan

**Go to:** Sidebar → Evaluation Plan

Set up in this exact order:

1. **Academic Year** → Click Add → Enter label (e.g. 2026-27), start year, end year → Set as Active → Save
2. **Semester** → Click Add → Select academic year, enter semester number and label, dates → Save
3. **Division** → Click Add → Select semester, enter division name (e.g. Division A), capacity → Save
4. **Evaluation Cycle** → Click Add → Select semester, enter cycle number and label (e.g. Evaluation 1 — Mid Semester), dates → Save

---

## STEP 4 — Create Assessment

**Go to:** Sidebar → Assessments

1. Click **Add Assessment**
2. Fill in:
   - Title (e.g. Case Study Assignment)
   - Select Course, Evaluation Cycle, Division
   - Type (Assignment, Exam, Project, etc.)
   - Total Marks (e.g. 30)
   - Passing Marks
   - Submission Deadline
3. Click Save

---

## STEP 5 — Build Rubric Matrix

**Go to:** Sidebar → Rubric Matrix

1. Select the assessment you just created
2. Click **Add Criterion** for each evaluation parameter:
   - Enter criterion title (e.g. Understanding of Concepts)
   - Set maximum marks
   - Select Bloom's taxonomy level
   - Add performance levels: Excellent, Good, Satisfactory, Needs Improvement
   - For each level: set marks range and descriptor text
3. Repeat for all criteria (total marks across all criteria must equal assessment total)
4. Click **Publish Rubric** when done

---

## STEP 6 — Add Students

**Go to:** Sidebar → Students

**Option A — Add individually:**
1. Click **Add Student**
2. Enter roll number, first name, last name, email
3. Select program, division, batch
4. Save

**Option B — Bulk import via Excel:**
1. Click **Import Excel**
2. Download the sample template
3. Fill in student data in the template
4. Upload the filled Excel file
5. Map columns and confirm import

---

## STEP 7 — Record Student Submissions

**Go to:** Sidebar → Student Submissions

1. Select assessment from the dropdown
2. For each student, click **Mark Submitted**
3. Optionally upload student files (PDF, DOCX, etc.) as evidence
4. Set submission date and mark if late

---

## STEP 8 — Enter Marks / Evaluate

**Option A — Teacher Evaluation (criterion-by-criterion):**

**Go to:** Sidebar → Teacher Evaluation

1. Select assessment
2. Click **Evaluate** next to a student
3. For each criterion, select the performance level (Excellent / Good / Satisfactory / Needs Improvement)
4. Marks are auto-calculated based on rubric levels
5. Add overall feedback
6. Click **Save Evaluation**
7. Repeat for all students

**Option B — Bulk Marks Upload (Excel):**

**Go to:** Sidebar → Bulk Marks Upload

1. Click **Download Template** to get the Excel format
2. Fill in marks for all students
3. Upload the filled Excel file
4. In the **Column Mapping** wizard, map each Excel column to the correct criterion
5. Review validation errors if any
6. Confirm and submit

---

## STEP 9 — View Analysis Dashboard

**Go to:** Sidebar → Analysis Dashboard

Select the assessment to see:
- Class average, highest, lowest scores
- Grade distribution chart (Excellent / Good / Satisfactory / Needs Improvement)
- Criterion-wise attainment bar chart
- Division-wise comparison
- Students who need improvement highlighted in red

---

## STEP 10 — Generate Reports

**Go to:** Sidebar → Reports

1. Select assessment from the dropdown
2. Choose report type:
   - **Evaluation Report** — criterion-wise performance, student-wise results, attainment %
   - **Submission Compliance** — who submitted, who didn't, late submissions
3. Click **Export PDF** to download

---

## STEP 11 — Track Student Progress

**Go to:** Sidebar → Student Progress

1. Search for a student by name or roll number
2. Click the student to view:
   - Score progression chart across all evaluation cycles
   - Evaluation history table with grades
   - Trend analysis (improving / declining)

---

## STEP 12 — Evidence Repository

**Go to:** Sidebar → Evidence Repository

1. Select an assessment to see all uploaded student files
2. Preview or download individual files
3. Click **Download All** to get a ZIP of all evidence files for accreditation

---

## STEP 13 — Accreditation Evidence Pack

**Go to:** Sidebar → Accreditation

1. Review the checklist of accreditation requirements
2. Check off completed items
3. Generate the evidence pack for NAAC / NBA submission
4. Download the compiled report

---

## STEP 14 — Continuous Improvement (CQI)

**Go to:** Sidebar → Continuous Improvement

After reviewing analysis results:
1. Click **Add Action**
2. Enter the weak area identified (e.g. Low attainment in CO3)
3. Enter evidence source (e.g. Evaluation 2 Data)
4. Describe the proposed action
5. Assign responsibility and target date
6. Track status: Planned → In Progress → Completed
7. Add outcome notes when action is completed

---

## Quick Reference — Correct Setup Order

```
Institution → Department → Program → Course
     ↓
Academic Year → Semester → Division → Evaluation Cycle
     ↓
Assessment → Rubric Matrix
     ↓
Students → Submissions → Evaluations
     ↓
Analysis → Reports → Evidence → CQI
```
